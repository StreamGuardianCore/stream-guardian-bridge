Stream Guardian — OBS Bridge
============================

1. Double-click  "Start Stream Guardian"
2. Enter the Bridge Code from your Stream Guardian dashboard
   (Settings -> OBS Connection)
3. Make sure OBS Studio is running with WebSocket enabled
   (Tools -> WebSocket Server Settings)
4. Click "Connect Bridge"

Keep this app running while you stream.

Need help?   https://www.streamguardian.co.uk/contact
